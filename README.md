# Mod-CK3

Collection de sous-mods Crusader Kings III pour **A Game of Thrones** (AGOT), conçus pour fonctionner ensemble.

| Mod | Dossier | Contenu |
|---|---|---|
| AGOT - Dragon Chronicles | `agot_dragon_chronicles/` | Évènements aléatoires de dragons (paix et batailles) |
| AGOT - Sworn Houses | `agot_sworn_houses/` | Vassaux et IA réalistes : tempéraments, respect de la Couronne, querelles, guerre, cour |

## Installation
1. Cloner ce dépôt dans `Documents/Paradox Interactive/Crusader Kings III/mod/Mod-CK3`
2. Copier chaque fichier `*.mod` de la racine dans `Documents/Paradox Interactive/Crusader Kings III/mod/`
3. Activer le mod dans le lanceur, **après** A Game of Thrones

## Règles de la collection
- Chaque mod a son propre préfixe (`agot_dc_` pour Dragon Chronicles, `agot_sh_` pour Sworn Houses) : pas de collision d'identifiants.
- Aucun fichier d'AGOT ou du jeu de base n'est écrasé ; les on_actions sont ajoutés par fusion.
- Localisation en français (+ anglais).
