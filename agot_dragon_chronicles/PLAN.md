## 🛠 Technique
- Namespaces : `agot_dc` (paix), `agot_dc_battle` (batailles), préfixe `agot_dc_`
- Fréquence : pulse annuel ≈ 1 évènement tous les 3 ans par cavalier ; batailles 35 % de chance
- Localisation : français (copie FR dans le fichier anglais pour l'instant)
